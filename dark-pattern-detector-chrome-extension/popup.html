One-time visible-tab capture: this captures only the currently visible browser tab after you confirm below. It can analyze a rendered web page, image, or PDF. The image is processed in memory and immediately discarded; it is not uploaded or stored.

On supported pages, this first runs the extension's local text and visual rules and shows those findings immediately. When Chrome's optional on-device image model is available, it also saves only supported image-category labels and confidence. It never saves the image, a caption, OCR text, URLs, or account names. If the model is unavailable, capture still ends with deletion and no image signal.
